# taller: identifique el tipo de función 

Para cada caso, decida: ¿procedimiento o función con retorno? ¿Cuántos parámetros?   

1. Calcular el precio final de una boleta del Carnaval aplicando un descuento.
2. Imprimir en pantalla el horario de atención de un puesto de Barranquillita.   
3. Determinar si un número de cédula tiene el formato válido (verdadero/falso).   
4. Mostrar por pantalla una tabla de multiplicar completa de un número dado.   
5. Calcular el promedio de tres notas de un estudiante de la IUB.
