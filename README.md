# 💻 Prácticas de Programación y Lógica

Colección de algoritmos, talleres y ejercicios resueltos, desarrollados como parte de mi proceso de aprendizaje continuo y mis estudios en Ingeniería de Datos e Inteligencia Artificial.

**Objetivo:** Consolidar los fundamentos de programación, estructuras de datos y resolución de problemas algorítmicos.

## 🛠️ Tecnologías y Entorno de Desarrollo
- **Lenguajes:** Python, Java, R y C
- **Entorno:** Arch Linux 
- **Editor:** Zed

## 📁 Organización del Repositorio
El código está categorizado principalmente por tecnología para facilitar su lectura:

- `/python`: Fundamentos de sintaxis, variables y algoritmos básicos.
- `/java`: Ejercicios universitarios y lógica estructurada.
- `/r`: Talleres de introducción a la ingeniería.

## 📝 Enunciados de los Ejercicios
Para entender el contexto de cada solución, los enunciados y requerimientos de cada ejercicio, taller o examen se encuentran:
- Como comentarios explicativos en la parte superior de cada archivo de código.
- (En el caso de proyectos más largos) Dentro de un archivo de texto o PDF adjunto en la misma carpeta del ejercicio.
